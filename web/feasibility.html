How to read this page
  • n is the number of VNFs in the request, |F|. The number of MEC nodes |V| is the other axis.
  • Interactive: every instance finished, and none took more than 1 s. Feasible: every instance finished inside the time budget. Partial: some did not. Infeasible: none did. Once a chain length runs out of budget on a network, longer chains on that network are not run.
  • A finished run is a proof of optimality: every scheme it did not evaluate was cut by a valid lower bound.
  • Plain enumeration = measured time of one evaluation × the size of the space: what checking every combination one by one would cost.
  • LOA is paper 1's algorithm on its own, with the limits our experiments use (k ≤ 256, 2000 candidates per anchor). “No scheme” means it hit those limits before finding a feasible scheme, although one exists.
  • Re-run: cpp\bin\loa_hybrid.exe --feasibility --runs 5 --budget 10000 --out ..\web\data\feasibility.json
